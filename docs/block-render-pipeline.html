阶段说明 返回目录 ↑

1. 帧更新决定“哪些要准备”

GameUpdateFrame 先更新玩家、世界流式和后台 job，然后调用 RebuildDirtyChunkMeshes。它扫描已加载区块，只挑选 section->dirty 且没有重复排队的 section；无 worker 时同步构建，有 worker 时受空闲 job 槽和每帧预算限制。交互优先重建路径可在队列接近饱和时同步处理。

2. 网格构建决定“画什么几何”

RebuildChunkSectionMeshSync 根据 targetLod 分别生成 solid、water、flora。精确 LOD 使用完整方块快照和 greedy cube mesh；低 LOD 使用 heightfield，并为植物保留单独模型。

3. 面发射决定“每个面带什么数据”

AddBlockFaceInternal 为可见面写入 6 个顶点、法线、颜色和 UV。UV 来自 TextureForBlockFace(type, face)；AO 和本地点光通过第二组顶点属性传给 shader。

4. 可见性决定“这一帧提交哪些模型”

CollectSurfaceRenderItems 先做加载状态和 render distance，再做球体视锥裁剪。solid / flora 立即画，water 加入透明队列；球面地表会使用 patch transform 把局部网格弯到行星表面。

5. 渲染器决定“用哪条材质路径”

WorldRendererDrawModel 选择 surface 或 water shader，叠加 section transform。单 mesh 走 DrawMesh；资源不可用时退回 raylib 的 legacy DrawModel。

6. shader 决定“像素最终长什么样”

顶点 shader 传递位置、UV、法线、AO 和颜色。片元 shader 用颜色图集、材质图集、法线图集取样，再计算直射光、环境光、阴影、火把光、发光、雾和色调；水面额外做波动与透明混合。

渲染范围之外如何处理 返回目录 ↑

先算玩家眼睛高度对应的 effectiveRenderDistance。地表区块距离使用 chunk 网格上的最大轴距离；球面地表在跨接缝时取最短地图偏移。绘制、预加载、释放是三步不同的判断。

位置 / 状态CPU / 内存处理屏幕结果
在当前半径内，但不在镜头视锥内区块仍可加载、更新和持有模型；SphereInFrustum 让该 section 跳过当帧绘制。不产生对应的 solid / flora / water 绘制。
超出当前半径，但在移动方向的预测半径内标为 preloaded，可以提前生成并留在内存；当前相机距离检查仍会跳过它。暂时不画，进入当前半径后可更快显示。
同时超出当前与预测半径ReclassifyStreamingWork 移除索引、释放 section 存储与模型，清除 loaded / preloaded；未运行的远处生成任务会取消。后台 mesh 结果用目标匹配保护，避免旧结果进入新 chunk。没有地表方块模型可画。
再次走近EnsureChunk 重新生成地形，并通过 ApplyEditsToChunk 重放已记录的方块改动；随后重新建模。新区块模型准备好后重新出现。

范围并非圆形。平面地表的距离是 max(abs(dx), abs(dz))，所以水平覆盖区是以玩家所在 chunk 为中心的方形。视锥裁剪在此之后执行；LOD 只降低范围内较远区块的网格精度，不负责把无限远地形持续画出来。

平坦地形的视觉误差。当 render distance 为 1 时，仍会绘制玩家区块及周围 8 个区块，即 3×3 个 16×16 区块。平地高度一致、纹理连续且没有明显接缝，屏幕上会像一整片很远的平面；几何范围仍只有约 48×48 方块，斜向最远约 45 个方块。

关键分支 返回目录 ↑

分支触发位置显示结果
精确 LOD / 低 LODRebuildChunkSectionMeshSync精确：完整方块面 + greedy；低 LOD：heightfield + LOD 植物 / 水模型。
平面 / 球面地表CurveChunkMeshData、LocalizeChunkMeshData球面把局部 section 曲到行星表面；平面把顶点平移到 chunk 世界坐标。
实体 / 透明水CollectSurfaceRenderItems、DrawWorldsolid 和 flora 直接提交；water 按距离排序，在 alpha blend 水通道绘制。
实时 shader / legacyWorldRendererDrawModelshader、图集、uniform 都就绪时使用实时光照；否则使用 raylib 默认材质路径。
后台 / 同步网格任务RebuildDirtyChunkMeshes、RebuildDirtyChunkMeshAt通常由 worker 构建；没有 worker 时同步构建。交互优先路径可在队列接近饱和时同步处理。

一个容易忽略的时序：网格重建发生在本帧绘制之前，但后台任务完成后，section 还要经过模型替换和 active LOD 刷新，下一次收集阶段才会拿到新模型。

记忆要点 返回目录 ↑

BlockType → section snapshot → mesh (solid / water / flora) → visibility → Model transform → shader atlas sample → lighting / fog → framebuffer

因此，方块的“显示”不是每帧逐块调用绘制，而是先把大量方块压缩成 section 级网格模型，再用距离、视锥和 LOD 控制提交数量。纹理外观来自颜色图集，材质属性来自并行材质图集，最终颜色由 world / water shader 合成。
